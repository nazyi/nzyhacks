**Terminology**

Data: A meaningful, unprocessed piece

Information: Processed data

Information Systems and Management: Infrastructure and services

**Regulation**

_GDPR (General Data Protection Regulation)_ is a data security regulation prepared by the European Union to protect personal data. It aims to protect individuals' privacy rights in the processes of processing, storing, and sharing their personal data. GDPR covers not only companies within EU borders, but also organizations worldwide that process the data of EU citizens. It is similar to Turkey's KVKK.

_The NIS (Network and Information Systems) Directive_ is a cybersecurity regulation aimed at improving the security of network and information systems. It requires critical infrastructures (such as energy, transportation, healthcare, and finance) and digital service providers to take the necessary measures to secure themselves against cyberattacks.

_PCI DSS (Payment Card Industry Data Security Standard)_ is a global security standard created to **protect credit card information** used in card payment systems. It was developed by card providers such as Visa, Mastercard, and American Express. This standard requires all organizations that process, store, or transmit cardholder information to comply with certain security measures.

**Cyberattacks**

*   **Malware:** Includes malicious software such as viruses, Trojan horses, and worms. This software can disrupt systems by gaining unauthorized access to devices, or grant attackers remote control.
*   Virus → Attaches itself to a file, waits to be opened to spread.
*   Trojan Horse → An enemy disguised as a friend, you download it yourself.
*   Worm → Spreads by itself using networks, doesn't even ask anyone!
*   **Phishing:** Aims to capture users' personal information (passwords, credit card details) through emails or messages that appear to come from trusted sources. Information is usually collected by redirecting to fake websites.
*   **Denial of Service (DoS) and Distributed Denial of Service (DDoS):** Attacks that cause a website or network to slow down or crash completely by sending an excessive number of requests. DDoS attacks are carried out simultaneously from multiple computers.
*   **Man in the Middle:** Attackers gain access to sensitive information by secretly listening to or altering the communication between two parties. For example, users' data can be captured by creating fake Wi-Fi networks.
*   **SQL Injection:** Allows attackers to gain unauthorized data access or perform manipulation by injecting malicious SQL code into vulnerable databases.
*   **Ransomware:** Blocks access by encrypting users' files and demands a ransom to decrypt them. There has been a significant increase in this type of attack in recent years.
*   **Cryptojacking:** Cryptocurrency mining software is installed on users' devices without permission, misusing the devices' processing power. This causes a drop in device performance and increased energy consumption.
*   **Zero Day Exploit:** Attacks carried out by exploiting software vulnerabilities that have not yet been discovered or patched. Such vulnerabilities give attackers the opportunity to infiltrate systems.
*   **Fileless Malware**: Unlike traditional malware, this is a type of malicious software that does not have a file-based structure and does not leave a physical file on the system. This type of malware runs in memory (RAM), temporarily bypassing the operating system and security software.
*   **Drive-By-Download:** A type of cyberattack in which malicious software is automatically downloaded when a user visits a website without realizing it.
*   **Rootkit Attacks:** Rootkit attacks allow an attacker to secretly infiltrate a system, gain unauthorized access, and maintain that access undetected for a long time.
*   **Tailgating:** A type of attack that occurs when one person follows another person who is trying to enter a secure area.
*   **Quid Pro Quo**: A situation in which the attacker promises something in return in order to manipulate a target. That is, the attacker tries to get **information** or **help** from the target person by offering a certain benefit or advantage.
